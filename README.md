# Phoenix OCR

An OCR processing pipeline project.

## Directory Structure

- `input/`: Input images or document files
- `output/`: Processed outputs
  - `pages/`: Extracted page images
  - `cleaned/`: Preprocessed/cleaned images
  - `json/`: OCR results in JSON format
  - `debug/`: Intermediate debug output
- `src/`: Source code
- `tests/`: Unit and integration test suites
- `benchmarks/`: Performance and accuracy benchmarks
- `docs/`: Project documentation
- `models/`: Model checkpoints and weights
- `assets/`: Project static assets
